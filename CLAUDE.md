# CLAUDE.md

## Result tables

In the result tables (README.md and `results/results.md`), bold any `Cold (s)` or `Hot (s)`
value under 2 seconds, e.g. `**1.07**`. Values of 2s or more stay plain.

Cacheless tools (Mago, ECS --blink) keep no cache, so cold == hot. Show one value in the
`Cold (s)` cell and leave the `Hot (s)` cell blank.
